# AI SOUND ENGINEER v2.0 — Natural Voice + AI Space Acoustics

Бесплатное локальное веб-приложение для анализа и обработки аудиофайлов с дополнительным анализом фотографии помещения.

## Что добавлено в v2

- Загрузка фотографии комнаты (JPG, PNG, WEBP, до 12 МБ).
- Опциональный семантический анализ фото локальной vision-моделью через Ollama.
- Возвращает видимые поверхности, предполагаемый риск отражений и осторожную рекомендацию.
- Передача фото-профиля в цепочку обработки голоса.
- Для естественного голоса используются мягкие настройки и ограниченное влияние фото.
- Без vision-модели приложение показывает, что распознавание недоступно; оно не выдаёт пиксельную статистику за распознавание комнаты.

## Честное ограничение

Одна фотография НЕ может достоверно определить акустику: RT60, точные размеры, скрытые материалы, расположение микрофона, уровень и характер эха в конкретной записи. В v2 фото — только слабый контекст. Оно не запускает искусственное добавление реверберации и не обещает удаление эха. Для реальной акустической оценки нужна запись тестового сигнала/импульсной характеристики или хотя бы запись голоса с анализом реверберации.

## Установка

Требуется Python 3.10–3.12.

### Windows PowerShell

```powershell
cd ai_sound_engineer_v2
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000

### macOS / Linux

```bash
cd ai_sound_engineer_v2
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

## Включение локального AI Vision (необязательно)

Для распознавания видимых объектов и поверхностей используйте Ollama локально. Установите Ollama с официального сайта, затем скачайте совместимую vision-модель:

```bash
ollama pull qwen2.5vl:3b
```

Убедитесь, что Ollama запущена и доступна по адресу `http://127.0.0.1:11434`.
После этого перезапустите AI SOUND ENGINEER. По умолчанию приложение использует:

- `OLLAMA_URL=http://127.0.0.1:11434`
- `VISION_MODEL=qwen2.5vl:3b`

Можно указать другую модель, поддерживающую изображения и Ollama API.

PowerShell, если нужна другая модель:

```powershell
$env:VISION_MODEL="qwen2.5vl:3b"
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Если Ollama недоступна, API вернёт безопасный fallback с пометкой `basic_image_statistics_only`; он не определяет материалы и не влияет на звук.

## Архитектура

```text
Browser UI
  |-- photo upload --> FastAPI /api/room/analyze
  |                       |
  |                       +--> Ollama Vision (optional, local)
  |                       +--> safe fallback (no semantic claims)
  |                       |
  |                       +--> room profile JSON
  |
  +-- audio upload --> FastAPI /api/process
                          |
                          +--> DSP: noise gate / HPF / EQ / compressor
                          +--> tiny cautious photo-context adjustment
                          +--> WAV PCM 24-bit export
```

## Использование на телефоне

Запустите сервер на компьютере с `--host 0.0.0.0`, узнайте IP компьютера в домашней Wi-Fi сети и откройте `http://IP-КОМПЬЮТЕРА:8000` на телефоне. Не открывайте порт в интернет: в этой версии нет аутентификации и TLS.

## Приватность и файлы

Обработка выполняется локально. Фотография передаётся локальному Ollama, если он запущен на этом компьютере. В fallback изображение анализируется локально. Загруженные аудиофайлы и готовые WAV хранятся в `work/`; удаляйте их вручную после работы.
