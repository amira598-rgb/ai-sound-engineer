# AI SOUND ENGINEER v2.1 — исправленная сборка

## Важно про размещение

GitHub Pages размещает только статические файлы. Python/FastAPI (`app.py`) нужно запускать отдельно на компьютере или на Python-хостинге. Если сайт открыт на GitHub Pages, укажите полный HTTPS URL API в поле «Адрес FastAPI-сервера».

## Локальный запуск

Требуется Python 3.10–3.12.

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\Activate.ps1
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Установка и запуск:
```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000

## Размещение API отдельно от GitHub Pages

1. Разместите папку проекта на Python-хостинге, который поддерживает постоянный процесс FastAPI.
2. Команда запуска: `uvicorn app:app --host 0.0.0.0 --port $PORT` (если хостинг предоставляет PORT; иначе используйте его инструкцию).
3. Установите переменную `ALLOWED_ORIGINS` в `https://amira598-rgb.github.io`.
4. Откройте GitHub Pages, в поле API введите HTTPS-адрес API и нажмите «Проверить соединение».
5. Убедитесь, что `https://ВАШ-API/api/health` возвращает JSON со `status: ok`.

Не используйте `http://localhost` в поле API на GitHub Pages: это будет компьютер посетителя, а не сервер в интернете.

## Необязательный анализ фотографий

Для локального анализа изображений установите Ollama и модель `qwen2.5vl:3b`. Запустите Ollama на том же сервере, где работает FastAPI, и задайте:
- `OLLAMA_URL` — адрес Ollama, по умолчанию `http://127.0.0.1:11434`
- `VISION_MODEL` — по умолчанию `qwen2.5vl:3b`

Если Ollama недоступна, API честно сообщает, что семантический анализ фотографии недоступен. Фото не определяет RT60 или реальное эхо.

## Что исправлено

- Добавлен CORS для GitHub Pages с настройкой разрешённых доменов.
- Интерфейс поддерживает отдельный адрес FastAPI и проверку `/api/health`.
- Исправлены URL загрузки обработанного WAV.
- Убрана путаница между сообщением о смене фотографии и ошибкой анализа.
- Добавлены проверки пустых и слишком больших файлов.
- Исправлена компрессия на коротких записях: вместо `np.convolve(..., mode="same")` используется фильтр фиксированной длины.
- Добавлен безопасный fallback для коротких файлов при фильтрации.

## Ограничения

Это классическая DSP-обработка (шумоподавление, фильтрация, EQ, компрессия и нормализация), а не нейросетевая модель восстановления речи. Она не гарантирует полного удаления шума или эха. Перед публикацией прослушайте результат.

На публичный сервер нельзя выкладывать эту сборку без дополнительной защиты: аутентификации, лимитов запросов, очистки старых WAV и TLS. Не запускайте Ollama с открытым доступом в интернет.
